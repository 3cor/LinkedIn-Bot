📋 How to Use in index.html

  1. Run the bot to capture job data (it will now save actual URLs)
  2. Run python app.py to start the Flask server
  3. Open http://localhost:5000 in your browser
  4. Look for the "External Link" column in the table
  5. Jobs with URLs will show "Open" and "Copy" buttons
  6. Click "Open" to visit the application page in a new tab
  7. Click "Copy" to copy the URL to your clipboard
